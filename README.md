## 🎮 遊戲核心特點

1. **教學核心對齊**：
   - 掌握色彩單字：`red`, `blue`, `yellow`, `black`, `white`, `purple`, `orange`, `green`, `gray`。
   - 掌握核心句型：
     - `"Red and blue make purple."`
     - `"Red and yellow make orange."`
     - `"Blue and yellow make green."`
     - `"Black and white make gray."`
2. **沉浸式 3D 視覺（Three.js）**：
   - 金邊煉金術木桌、3D 魔法坩堝 (Cauldron)、動態沸騰彩色泡泡 (Bubbles) 與懸浮魔杖 (Magic Wand)。
   - 點擊「✨ Stir & Mix!」時，魔杖自動在坩堝上方旋轉攪拌，藥水即時平滑變色，過關噴發彩帶！
3. **極致流暢與零依賴音效**：
   - 原生 **Web Audio API** 即時合成音效（清脆波浪水滴音、啵啵冒泡聲、三和弦過關音效）。
   - **Web Speech API (TTS)** 雙軌語音，落實 *"Say it to Play it"* 原則，點選顏色、過關造句全程大聲朗讀。
4. **低配友善與無挫折體驗**：
   - 限制 Pixel Ratio，輕量化網格，平板與低階筆電維持 60 FPS。
   - 選錯顏色不扣分或淘汰，播放趣味攪拌灰色反饋並引導重試。
